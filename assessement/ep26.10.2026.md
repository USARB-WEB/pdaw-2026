
# Lucrare practică: machetarea unei pagini web după design

Fiecare student primește de la profesor **o variantă**: un fișier `NN-tema.svg` (de exemplu `07-clinica-veterinara.svg`).
Sarcina este să reproduceți pagina cât mai fidel, folosind **doar HTML și CSS**.

👉 **Exemplu (varianta 01) în Figma:** [EP 25.10.2025 – Exemplu](https://www.figma.com/design/6W22rZrQSp6wdYvbDBhsPw/EP-25.10.2025---Exemplu?node-id=0-1)
Toate variantele au aceeași structură ca acest exemplu; diferă tema, culorile, fonturile și așezarea elementelor din secțiuni.

---

## 1. Deschiderea machetei în Figma

1. Intrați pe [figma.com](https://figma.com) și faceți-vă un cont gratuit.
2. **+ Create → Design file**.
3. Trageți fișierul `.svg` al variantei voastre peste pânza goală. Apăsați **Shift + 1** ca să vedeți toată pagina.
4. Dați click pe orice element ca să vedeți în panoul din dreapta **culoarea, fontul, mărimea textului, dimensiunile și colțurile rotunjite**. Distanța dintre două elemente o vedeți dacă selectați unul și țineți apăsat **Alt** deasupra celuilalt.
5. **Pozele:** selectați imaginea → în dreapta jos **Export** → **JPG** → **Export**. Salvați-le în folderul `img/` al proiectului.

> În panoul **Layers** din stânga, straturile au nume. Unele spun și ce tehnică trebuie folosită, de exemplu `2 Header (sticky)`, `Etichetă (absolute)`, `11 Buton chat (fixed)`.

**Fonturile** sunt de pe [Google Fonts](https://fonts.google.com). Numele lor apare în Figma când selectați un text. Le includeți cu `<link>` în `<head>`.

---

## 2. Structura paginii

Toate variantele au aceeași structură, de sus în jos:

| Nr. | Secțiune | Ce exersați |
|---|---|---|
| 1 | Bara de sus (contact, program) | flex, `justify-content: space-between` |
| 2 | Header: logo, meniu, buton | flex, **`position: sticky`** (rămâne lipit sus la scroll) |
| 3 | Hero: titlu mare, text, butoane, imagine | flex, **`position: absolute`** pentru elementele puse peste imagine (carduri, cerc, bandă cu cifre) |
| 4 | Avantaje | **grid** cu coloane egale |
| 5 | Produse / servicii (carduri) | **grid**, **`position: absolute`** pentru etichetele de pe imagini (`-15%`, `NOU`…) |
| 6 | Recenzii | flex sau grid, avatare rotunde (`border-radius: 50%`) |
| 7 | Galerie | **grid** cu imagini pe mai multe coloane sau rânduri (`grid-column: span 2`, `grid-row: span 2`) |
| 8 | Ofertă: prețuri / meniu / orar | grid, flex sau `<table>`, în funcție de variantă |
| 9 | Abonare (formular) | `<form>`, `<input>`, `<button>` |
| 10 | Footer | grid sau flex, link-uri, iconițe sociale |
| 11 | Butonul plutitor (chat, coș, „sus”, apel) | **`position: fixed`** (stă mereu în colțul ecranului) |

---

## 3. Ce trebuie făcut

### ✅ În clasă (90 min) – obligatoriu

1. Creați repository-ul pe GitHub și primul commit (vedeți punctul 4).
2. **Structura HTML a întregii pagini**: toate cele 11 părți, cu tag-uri semantice (`header`, `nav`, `main`, `section`, `footer`), chiar dacă nu au încă stiluri.
3. Secțiunile **2 Header**, **3 Hero**, **4 Avantaje** și **5 Produse**, cu stiluri complete.

### 🏠 Acasă – termen: lecția următoare

4. Secțiunile **1, 6, 7, 8, 9, 10** și butonul plutitor **11**.
5. **Bonus:** efecte `:hover` pe butoane, linkuri și carduri, cu `transition`; publicarea pe **GitHub Pages**.

---

## 4. GitHub – progresul pe pași

Lucrarea se predă **doar prin GitHub**. Istoricul commit-urilor face parte din notă.

**Repository:** public, cu numele `pdaw-macheta-NN` (`NN` = numărul variantei voastre).

**Structura proiectului:**

```
pdaw-macheta-NN/
├── index.html
├── css/
│   └── style.css
├── img/
│   └── ...pozele exportate din Figma
└── README.md        ← numele vostru, grupa, numărul variantei, link-ul GitHub Pages
```

**Reguli pentru commit-uri:**

- **Cel puțin un commit pentru fiecare secțiune**, imediat ce ați terminat-o, urmat de `git push`.
- Mesajele spun ce ați făcut, de exemplu:
  ```
  Structura HTML a paginii
  Secțiunea 2: header sticky
  Secțiunea 3: hero cu carduri absolute
  Secțiunea 5: carduri produse în grid
  Secțiunea 11: buton fixed
  ```
- Nu faceți un singur commit cu tot proiectul la final. Lucrarea **nu se acceptă** fără istoric pe pași.
- Commit-urile din clasă trebuie să aibă data și ora lecției.

---

## 5. Reguli

- Fără framework-uri CSS (Bootstrap, Tailwind etc.) și fără JavaScript.
- Fără stiluri inline (`style="..."`); tot CSS-ul stă în `css/style.css`.
- Pagina are 960px lățime și este centrată (`max-width: 960px; margin: 0 auto;`).
- Iconițele sunt emoji, deci nu aveți nevoie de imagini pentru ele.
- Pozele din machete sunt de pe Wikimedia Commons, cu licențe libere (CC). În `README.md` scrieți: „Imagini: Wikimedia Commons”.
- Codul îl scrieți voi. Două lucrări cu cod identic primesc nota 1 amândouă.

---

## 6. Evaluare (10 puncte)

| Criteriu | Puncte |
|---|---|
| Structura HTML semantică, cod curat și indentat | 1 |
| Header sticky + bara de sus | 1 |
| Hero, cu elementele absolute la locul lor | 1,5 |
| Avantaje + produse (grid, etichete absolute) | 2 |
| Recenzii + galerie (grid cu span) | 1,5 |
| Ofertă + abonare + footer | 1 |
| Butonul fixed | 0,5 |
| Fidelitate față de machetă (culori, fonturi, distanțe) | 0,5 |
| **Istoricul GitHub**: commit-uri pe secțiuni, mesaje clare, ritm constant | 1 |
