Hyperlinks

Hyperlinks are used to link from one page to another. The most important element in HTML for creating hyperlinks is the anchor tag, which is defined with the <a> tag.

The anchor tag requires the href attribute, which indicates the link's destination. The text between the opening and closing anchor tags is what will be visible to users as clickable text.

Here is an example of a hyperlink:

Visit Example.com

Types of Hyperlinks

  • Absolute URL: Links to a specific website or page, e.g., <a href="https://www.example.com">Example</a> Visit Example.com
  • Relative URL: Links to a page within the same website, e.g., <a href="about.html">About Us</a> About Us
  • Email Link: Opens the user's email client to send an email, e.g., <a href="mailto:example@example.com">Email Us</a> Email Us

Target Attribute

The target attribute specifies where to open the linked document. Common values include:

  • _self: Opens the link in the same tab (default) Open in same tab
  • _blank: Opens the link in a new tab Open in new tab
  • _parent: Opens the link in the parent frame Open in parent frame
  • _top: Opens the link in the full body of the window Open in top frame

Anchor Tags

Anchor tags can also be used to create bookmarks within a page. By using the id attribute, you can link to specific sections of a page.

For example, if you have a section with an id of "section1", you can create a link to it like this:

Go to Section 1 Go to Section 2 Go to Section 3 Go to Section 4 Go to Section 5
